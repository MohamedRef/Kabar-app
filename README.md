# Kabar

> *Apa kabar?* — from خبر to **kabar**.

Kabar is a personal Indonesian + Javanese learning app written in Rust, for one
learner: an Egyptian Arabic native who reads English. Explanations come in
Egyptian Arabic, Modern Standard Arabic and English, and every lesson leans on
the Arabic words Indonesian already borrowed.

| | |
|---|---|
| **Use** | Personal only. Never published to a store. |
| **Release** | None yet. The first one will be an **alpha**: a signed, sideloaded APK for the phone and tablet plus a local Mac app ([docs/RELEASE.md](docs/RELEASE.md)). |
| **Cost to run** | $0/month (free tiers only; see [docs/RESEARCH.md](docs/RESEARCH.md)). |
| **Devices** | MacBook Air M2, Galaxy S24 Ultra, Galaxy Tab S11. Layout follows window width, not device. |
| **Content status** | All written content is a draft until the learner approves it. A lesson counts as approved once it is passed with 80% or more. |

## Build and run

Everything runs from the repo root with [`just`](https://github.com/casey/just)
(`brew install just`). Full instructions: [docs/RUN.md](docs/RUN.md); the
first Mac session is a checklist in [docs/MAC-TODO.md](docs/MAC-TODO.md).

| Platform | Command | Result |
|---|---|---|
| One-time setup (Mac) | `just setup-mac` | Rust targets, dx 0.7.10, Java 17, Android SDK + NDK |
| Quality gate | `just check` | fmt, clippy (zero warnings), all tests |
| Content gate | `just content-check` | schemas, glosses, Bridge, speech levels, golden sets, packs |
| Mac, dev | `just run-mac` | desktop app with hot reload |
| Phone layout on the Mac | `just run-phone-preview` | the app in a 412×915 window |
| Mac, app bundle | `just bundle-mac` | `dist/mac/Kabar.app` |
| Android, dev | `just run-android [device]` | live reload on a connected Galaxy |
| Android, release | `just android-keystore` (once), `just apk`, `just install <serial>` | signed `dist/android/kabar.apk` on the S24 Ultra or Tab S11 |
| Kabar Cloud, local | `just cloud-dev`, `just cloud-e2e` | Worker on `127.0.0.1:8787`; phone → tablet sync test |
| Kabar Cloud, deploy | `just cloud-setup` (once), `just deploy-cloud` | Worker on `*.workers.dev` ([docs/CLOUD.md](docs/CLOUD.md)) |
| Offline packs | `just packs`, `just packs-audio`, `just packs-bundle` | unit manifests, Azure F0 audio, release tars |
| README numbers | `just readme` | refreshes the table above |

Jump straight into a lesson or test: `KABAR_OPEN_LESSON=bipa1.u01.l01 just run-mac`.

## Repository layout

| Path | What |
|---|---|
| `crates/core` | Pure logic (language engine, FSRS, coach, journey, lessons, AI router). Builds for native and wasm32. |
| `crates/protocol` | Every type that crosses a process boundary (serde, versioned). |
| `crates/app` | The Dioxus app (Mac, Android). HTML/CSS UI, SQLite store, sync client. |
| `crates/server` | Kabar Cloud, a Cloudflare Worker (workers-rs) with a Durable Object per account. |
| `crates/content` | Content model, loaders and validation (`cargo test -p kabar-content`). |
| `crates/tools` | `kabar-tools`, the build-time content pipeline (glosses, Bridge, bake-off, packs, README numbers). |
| `android/` | The minimal Kotlin glue: share target, OCR, TTS, background playback. |
| `curriculum/` | BIPA 1–7 and J1–J6: levels → units → lessons ([curriculum/README.md](curriculum/README.md)). |
| `content/` | Lessons, tests, grammar, glosses, Bridge, stories, radio, games, packs ([content/README.md](content/README.md)). |
| `prompts/` | Versioned AI prompts and `routes.toml` (which free engine serves each task). |
| `schemas/` | JSON Schemas generated from the Rust content types. |
| `fixtures/` | Recorded AI replies; tests never call live APIs. |
| `assets/` | Icons, Journey Map and souvenir art. |
| `scripts/` | Setup, signing, fetch and asset scripts. |
